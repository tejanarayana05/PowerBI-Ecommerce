# 📊 E-Commerce Sales Analysis Dashboard – Power BI

![Power BI Logo](https://upload.wikimedia.org/wikipedia/commons/c/cf/New_Power_BI_Logo.svg)

## 🧾 Project Summary

This project presents a comprehensive Power BI dashboard that analyzes sales data from an e-commerce platform. The goal is to uncover insights that help optimize operations, improve customer understanding, and **boost profitability**.

📁 **Dataset Source**:  
🔗 [Unlock Profits with E-Commerce Sales Data – Kaggle](https://www.kaggle.com/datasets/thedevastator/unlock-profits-with-e-commerce-sales-data)

## 📌 Dashboard Highlights

### 🔹 Sales Overview
- Total Revenue, Orders, Quantity, and Profit KPIs
- Drill-down by Year, Month, and Week

### 🔹 Category & Product Performance
- Best-performing Categories and Sub-Categories
- Revenue and Profit trends by Product Name


### 🔹 Profitability Insights
- Profit Margin by Product and Region
- Correlation between Quantity Sold and Profit
